## 首页自动跳转

默认将微博首页跳转到当前登录账号的「最新微博」，支持直接打开首页和站内返回首页。

在「药方设置 → 页面跳转」中可以关闭「进入首页时自动跳转到最新微博」。修改后刷新页面生效。

使用此功能请将本仓库的 `yyawf.user.js` 导入脚本管理器。
